## Framework note

The declared primary framework is the **HIPAA Security Rule**. There is no NIST-published HIPAA
OSCAL catalog, and HIPAA `164.x(...)` identifiers contain parentheses that OSCAL control-id tokens
reject. So the component cites the equivalent **NIST 800-53 Rev 5** control ids and preserves the
HIPAA citation in a `hipaa-control` prop on each `implemented-requirement`.

## Controls implemented

| 800-53 | HIPAA (`hipaa-control` prop) | Description | Key Terraform resource |
|---|---|---|---|
| SC-28 | 164.312(a)(2)(iv) | PHI encryption at rest with a customer-managed KMS key | `aws_kms_key.phi` |
| SC-8 | 164.312(e)(1) | TLS-only bucket policy; Lambda in VPC; VPC endpoints | `aws_s3_bucket_policy.uploads_tls_only` |
| CP-9 | 164.308(a)(7) | S3 versioning + Object Lock on the evidence vault | `aws_s3_bucket_versioning.uploads` |
| AC-3 | 164.312(a)(1) | Least-privilege Lambda IAM; wildcard block in CI | `aws_iam_role_policy.lambda_least_privilege` |
| AU-2 | 164.312(b) | CloudTrail (multi-region, log-file validation); signed evidence vault | `aws_cloudtrail.main` |
